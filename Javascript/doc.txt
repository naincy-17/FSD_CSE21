Why alert box appears first?
Used to show warning

Uses ASYNC AWAIT technology


Async/Await in JavaScript is a way to handle tasks that take time (like fetching data from a server) without stopping the rest of your code. async makes a function return a Promise, and await pauses inside that function until the Promise finishes, letting your code look simple and readable while still being non-blocking.
Blocking behavior:
alert() is a synchronous, modal function. When the browser encounters it,
everything else pauses until the user clicks OK.

Execution order:  
JavaScript runs top to bottom. If an alert is encountered, 
it halts the script at that exact line. 
Any earlier code that hasn’t finished rendering or displaying will wait.

Rendering vs. execution:  
Sometimes you write code that updates the page (like document.write() or console.log()), 
but the browser may not show those changes immediately if an alert interrupts. 
The alert forces the browser to stop and show the dialog before continuing.


Why console.log ?
For developers only → It prints messages in the browser’s console (inside Developer Tools), not on the webpage.

Purpose → Helps programmers check values, debug code, and understand what’s happening while the program runs.

Non-blocking → Unlike alert(), it doesn’t stop the page or annoy the user.

What is inner HTML ?
innerHTML is a property in JavaScript that lets you get or set the HTML content inside an element.

It belongs to the DOM (Document Object Model), meaning it works on elements you select with document.
